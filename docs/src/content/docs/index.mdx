## Three front-ends, one engine

Every front-end goes through the same engine, so the safety checks, history, and audit log behave the same wherever you work.

<Tabs>
	<TabItem label="Web app" icon="laptop">
		`tess serve` opens a fast, keyboard-friendly app in your browser: a schema tree, SQL tabs with completion, a virtualized grid, inline editing with a preview of the exact SQL, and a table designer.
		<Screenshot name="web-sql" alt="A SQL tab running a grouped query with results below" />
	</TabItem>
	<TabItem label="Terminal UI" icon="seti:shell">
		`tess tui` gives you the same tree, editor, and grid in any terminal, with a command palette, history, and light and dark themes. It works over SSH.
		<Screenshot name="tui-sql" alt="The Tessera terminal UI with a query and its results" />
	</TabItem>
	<TabItem label="Command line" icon="seti:powershell">
		`tess query` streams results as a table, CSV, or JSON, so it fits in scripts and pipelines. Ctrl+C cancels the statement on the server.

		```sh
		tess query -c app "SELECT id, total FROM orders WHERE placed_at > now() - interval '1 day'"
		tess query -c app -f csv "SELECT * FROM orders" > orders.csv
		tess query -c app < migrate.sql
		```
	</TabItem>
</Tabs>

## Why Tessera

<CardGrid>
	<Card title="Guardrails, not hope" icon="warning">
		`DROP`, `TRUNCATE`, and `UPDATE` or `DELETE` without `WHERE` ask first. Production connections make you type their name. A whole script is checked before its first statement runs.
	</Card>
	<Card title="Edits you can read" icon="pencil">
		Change cells in the grid, then preview the exact SQL. Edits run in one transaction, and if someone changed the row since you read it, nothing is applied.
	</Card>
	<Card title="Cancel means cancel" icon="close">
		Cancelling stops the work on the server, not only in the client. Results stream, so a billion-row table never fills your memory.
	</Card>
	<Card title="Lossless values" icon="seti:json">
		Big integers and decimals keep every digit, in the grid and in exports. Nothing passes through a float.
	</Card>
	<Card title="Secrets stay secret" icon="seti:lock">
		Passwords live in an encrypted vault keyed from your OS keychain, never in flags or config files, and are redacted from history and logs.
	</Card>
	<Card title="Open to any database" icon="puzzle">
		Other databases plug in as separate programs over a small JSON protocol. Plugins are signed, hash-pinned, and checked before every start.
	</Card>
</CardGrid>
